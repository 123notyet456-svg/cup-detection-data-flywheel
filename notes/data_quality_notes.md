# Data Quality Notes

## 项目目标
通过一个小型杯子图像数据集，完整实践：
原始数据 → 数据检查 → 清洗 → 标注 → 质检 → 数据集构建 → 模型训练 → 评估 → 失败分析。

---

# 1. 数据质量检查框架

每次拿到一批图像数据，先检查：

1. 文件是否能正常读取？
2. 格式是否正常、统一？
3. 尺寸和宽高比是否异常？
4. 是否存在完全重复图片？
5. 是否存在近似重复图片？
6. 图像是否模糊、过暗、过亮？
7. 图像内容是否符合任务要求？
8. 标注是否正确？
9. 数据分布是否合理？
10. train / val / test 是否存在数据泄漏？

### QC 检查项
1. 类别是否正确
2. 是否存在漏标
3. Bounding Box 是否完整覆盖目标
4. Bounding Box 是否过松
5. 相似样本的标注规则是否一致

### 标注原则
Bounding Box 应完整包含目标最外侧可见区域，
同时尽量减少无关背景。

困难样本如果仍可可靠识别和标注，应优先保留，
而不是仅因为遮挡、倾斜或暗光而删除。

### Pilot 结论
当前 Annotation Guideline 可以支持正常杯子目标的标注。
后续大规模标注前，应继续关注遮挡、小目标、多目标、
截断目标等边界样本。

## Pre-label QC 结果

随机抽样：20 张

### 质量判断

已有 YOLO 标签整体语义正确，没有发现明显漏标、错标或严重框错。

主要问题为 Bounding Box 普遍偏松，属于系统性的定位精度问题。

### 数据处理决策

不重新进行全量标注。

采用：

Existing Labels
→ Pre-label
→ Human Correction
→ Annotation QC
→ Final Ground Truth

对于 Accept 样本直接保留；
对于 Minor Fix 样本人工调整 Bounding Box；
如果后续发现 Major Fix 样本，则重新标注。

### 核心原则

标签质量问题需要区分：

- 系统性轻微误差
- 严重语义错误

不能因为标签不完美就全部重标，应根据 QC 结果选择成本和质量更优的数据生产策略。
